BRYAN LANE PORTFOLIO SITE

index.html      The website.
portfolio.csv   A backup copy of the spreadsheet. The site uses it only if the
                Google Sheet can't be reached.
images/         Put each piece's image here. The filename must match the
                "Image" column in the sheet exactly (for example, yes-events.png).

TO TURN A PIECE ON OR OFF
Open "Bryan Lane Portfolio — Control Panel" in Google Drive and check or
uncheck its box in the Include column. The live site updates within a few
minutes.

OTHER COLUMNS
Order       Lower numbers show first.
Best For    Tags like Marketing, Events, E-commerce, Design, Nonprofit,
            Property Management. Send a link ending in ?for=Events to show
            only the pieces tagged Events.
Link        A web address for the button in the pop-up (store, book page,
            YouTube). Leave Link blank and set Link Label to "Coming soon"
            to show a grayed-out "Coming soon" button.
Notes       Your own to-dos. They never appear on the site, but anyone with
            the sheet link could read them, so keep them non-private.
